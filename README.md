# Lingoza

**Learn a little. Grow a lot.**

Lingoza is a mobile-first, bilingual English-learning experience built around short lessons, clear progress, and playful practice.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Current MVP foundation

- Responsive learning dashboard with Arabic RTL and English LTR layouts.
- Language switcher.
- Daily goal, XP, streak, and weekly progress presentation.
- Learning-path preview with progressive units.
- Interactive vocabulary practice with answer feedback and XP.
- Responsive navigation for mobile screens.

## Product direction

The first release is intentionally AI-teacher-free. The initial focus is a polished, reliable self-study experience: structured lessons, vocabulary, listening and reading activities, review, achievements, and learner progress.

## Development principles

- Mobile-first, accessible interactions.
- Reusable components and consistent design tokens.
- No paid AI dependency in the first release.
- Keep learner progress local until a backend and account system are deliberately introduced.

## Status

Early MVP scaffold. Some dashboard metrics and learning-path cards are demonstration data; persistence, full lesson content, authentication, and production analytics are not implemented yet.
